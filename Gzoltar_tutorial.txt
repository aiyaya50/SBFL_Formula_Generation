Simple Guide to run Gzoltar on Java Programs
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~o~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~Step 1- list testmethod
	
pre-run: run the command mvn clean test-run or gradle clean test. 
mvn-based
compile_code="target/classes"
compile_test="target/test-classes"

java -cp $GZOLTAR_CLI_JAR:target/classes:$compile_test com.gzoltar.cli.Main listTestMethods $compile_test --outputFile tests.txt

key output - you will receive textfile with list of tests in work_dir

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~o~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
step-2 instrumentation
java -cp $GZOLTAR_CLI_JAR:$compile_code:$GZOLTAR_AGENT_JAR com.gzoltar.cli.Main instrument $compile_code --outputDirectory instrument-classes

output - new directory instrument-classes is created with compile code

step-3 run testMethod
java -cp $GZOLTAR_AGENT_JAR:$GZOLTAR_CLI_JAR:instrument-classes:$D4J_HOME/framework/projects/lib/junit-4.11.jar:$compile_test  com.gzoltar.cli.Main runTestMethods --testMethods tests.txt --collectCoverage --offline

key output: gzoltar.ser file will be created
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~o~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

step-4 fault localization

mvn-based
java -cp $GZOLTAR_CLI_JAR:$GZOLTAR_AGENT_JAR com.gzoltar.cli.Main faultLocalizationReport --dataFile gzoltar.ser  --buildLocation $compile_code --outputDirectory Result --formula ochiai:dstar:ochiai2:yaya
